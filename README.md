# web_shopping

Website bán hàng sử dụng PHP + MySQL.

## Công nghệ
- PHP
- MySQL
- HTML/CSS/JS
- Git + GitHub
- XAMPP

## Cách chạy project
1. Clone repo về máy
2. Đặt project trong thư mục `htdocs`
3. Mở XAMPP, chạy Apache và MySQL
4. Tạo database `web_shopping`
5. Import file `database.sql` bằng phpMyAdmin
6. Truy cập `http://localhost/web_shopping/user/index.php`

## Cấu trúc chính
- `user/`: giao diện người dùng
- `admin/`: giao diện quản trị
- `config/`: cấu hình project
- `includes/`: file dùng chung
- `controllers/`: xử lý logic
- `models/`: thao tác dữ liệu
